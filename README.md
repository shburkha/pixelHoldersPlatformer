## Controls

- **A**: Move the player left.
- **D**: Move the player right.
- **Spacebar**: Jump.
- **K**: Attack.
- **Escape**: Quit the game.
- **R**: Reset player position.
- **F**: Toggle camera render mode (the changes are visible in debug mode).
- **Keypad +** or **]**: Zoom in the camera.
- **Keypad -** or **/**: Zoom out the camera.
- **Keypad 0**: Reset camera zoom.
- **H**: Go to the last checkpoint.
- **F1**: Toggle debug mode.
